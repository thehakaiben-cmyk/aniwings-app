## 🪽 What is AniWings?

**AniWings** is a modern anime streaming client designed for **Android phones, tablets, Android TV, Google TV, Amazon Fire TV, and NVIDIA Shield TV**.

Discover anime, browse seasonal releases, follow airing schedules, manage your library, track episodes, use multiple providers, install provider extensions, download supported episodes, and watch through an interface designed specifically for both mobile devices and televisions.

> **No mandatory AniWings account. No intrusive advertising. Just anime.**

### Why AniWings?

- 🚫 **No Mandatory Sign-up** — Start browsing and watching without creating an AniWings account.
- 🎨 **Modern Interface** — A redesigned experience built for phones, tablets, and televisions.
- 🎬 **Multiple Providers** — Switch between available streaming sources when needed.
- 🔌 **Extension Support** — Expand AniWings Mobile with additional provider extensions.
- ⬇️ **Offline Downloads** — Download supported episodes for offline viewing.
- 📊 **Anime Tracking** — Support for AniList, MyAnimeList, Kitsu, and AniDB.
- 📺 **Dedicated TV Experience** — TV-optimized layouts with full D-pad navigation.
- 🗣️ **SUB & DUB** — Access subtitled and dubbed sources where available.

# 🔌 Mobile Extension Support

> ### 📱 Available on AniWings for Android Mobile

AniWings Mobile includes a modular **extension-based provider system** that allows users to expand the app with additional anime providers instead of relying entirely on the built-in servers.

### 🧩 Extension Manager

Install and manage supported provider extensions directly through AniWings.

Extensions can add their own:

- 🔍 Anime search
- 📚 Anime catalogs
- 📄 Anime information
- 🎞️ Episode lists
- 🎬 Streaming sources
- 🌐 Provider-specific functionality

### ⚡ How Extensions Work

Installed extensions operate separately from AniWings' built-in providers.

Once a compatible extension is installed, its supported sources can become available inside AniWings as additional provider options.

This gives the mobile app a more flexible architecture where additional compatible providers can be added without requiring every provider to be bundled directly into the main AniWings application.

### 🔧 Extension Features

- 🧩 **Install Extensions** — Add supported provider extensions from the Extension Manager.
- 📦 **Extension Management** — Manage installed provider extensions directly inside the app.
- 🔍 **Extension Search** — Search supported anime using installed extensions.
- 📺 **Additional Sources** — Extensions can provide additional episodes and playable sources.
- 🔄 **Independent Providers** — Extension providers work separately from built-in AniWings servers.
- ⚡ **Dynamic Provider Loading** — Installed extensions can appear as additional source options.
- 🛠️ **Expandable Architecture** — Additional compatible providers can be supported over time.
- 🌐 **Provider Flexibility** — Users aren't limited exclusively to AniWings' built-in server selection.

> **Note:** The Extension Manager is currently a **Mobile-only feature**. Extensions are not currently supported by the Android TV version. Availability and functionality can vary between individual extensions.

# 🔗 Mobile ↔ TV QR Login

AniWings Mobile can be used to connect with the Android TV version through **QR code pairing**.

Instead of manually entering account information using a television remote:

1. Open AniWings on your TV.
2. Select the QR login option.
3. Open AniWings on your Android phone.
4. Scan the QR code displayed on your television.
5. Complete the connection through the mobile app.

This makes signing in and linking the TV experience much easier.

# 🆘 Help & Support

Having trouble with AniWings?

Before reporting an issue:

1. Make sure you're using the **latest AniWings version**.
2. Try another available provider or server.
3. If you're using an extension, try another installed extension.
4. Check whether the problem happens with another anime or episode.
5. Restart AniWings.
6. If you're upgrading from an older incompatible build, uninstall the previous version and install the latest release.

### 🐛 Reporting Bugs

When reporting an issue, including the following information will make troubleshooting much easier:

```text
Device:
Android Version:
AniWings Version:
Mobile / TV:
Anime:
Episode:
Provider / Extension:
Issue:
```

Please avoid including private account information, email addresses, passwords, or other sensitive information in public bug reports.
